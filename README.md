# 🚀 Vitor Dev — Premium Developer Portfolio

A modern premium portfolio website built using only HTML, CSS and vanilla JavaScript.

Designed with a dark neon aesthetic, smooth animations, responsive layouts and a strong conversion-focused structure inspired by high-end creative developer portfolios.

---

## ✨ Features

- ⚡ Fully Responsive Design
- 🌙 Dark / Light Mode
- 🎨 Modern Neon UI
- 📱 Mobile-First Layout
- 🚀 Smooth Scroll Animations
- 🎯 Conversion-Focused Sections
- 🍔 Animated Fullscreen Menu
- 💡 Interactive Hover Effects
- 🧠 Clean Vanilla JavaScript
- 🇬🇧 British English Copywriting

---

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
